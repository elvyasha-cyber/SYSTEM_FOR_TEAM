# Тесты базы знаний

Примеры бьют в сервер `http://127.0.0.1:8080`. Его запускают из папки проекта командой `python -m server`. В PowerShell вызывайте `curl.exe`: имя `curl` там занято другим командлетом. Знак `--%` нужен, чтобы кавычки внутри JSON дошли до curl, а не снялись по дороге.

Перед `POST /kb/ask` в базе уже должны лежать документы из `kb_documents.jsonl`. Иначе вопрос из примера уйдёт в ручную проверку.

## POST /kb/documents

```powershell
curl.exe --% -s -X POST "http://127.0.0.1:8080/kb/documents" -H "Content-Type: application/json; charset=utf-8" --data-binary "{\"title\":\"Правила работы команды\",\"text\":\"Оператор отвечает клиенту не позже следующего рабочего дня.\"}"
```

## POST /kb/ask

```powershell
curl.exe --% -s -X POST "http://127.0.0.1:8080/kb/ask" -H "Content-Type: application/json; charset=utf-8" --data-binary "{\"question\":\"К какому сроку оператор должен ответить клиенту?\"}"
```

## POST /ai/answer_with_sources

```powershell
curl.exe --% -s -X POST "http://127.0.0.1:8080/ai/answer_with_sources" -H "Content-Type: application/json; charset=utf-8" --data-binary "{\"question\":\"К какому сроку оператор должен ответить клиенту?\",\"context\":\"Оператор отвечает клиенту не позже следующего рабочего дня. Молчание дольше этого срока считается пропущенным ответом.\"}"
```

## Десять вопросов

Номер — порядок строки в `kb_questions.jsonl`. Колонка «Почему» совпадает с полем `why`. Документ — тот, на котором стоит ожидаемый ответ. У вопросов 8–10 такого документа нет.

| № | Вопрос | expected_needs_review | Почему | Документ |
|---|---|---|---|---|
| 1 | К какому сроку оператор должен ответить клиенту? | false | В документе «Правила работы команды» сказано: оператор отвечает не позже следующего рабочего дня. | Правила работы команды |
| 2 | Что написать клиенту, если в базе нет нужного факта? | false | В документе «Правила работы команды» есть формулировка «Уточню и вернусь» и запрет выдумывать факт. | Правила работы команды |
| 3 | Что сказать клиенту, если срок задачи сдвинулся? | false | В документе «Частые вопросы клиентов» сказано называть новую дату и причину переноса. | Частые вопросы клиентов |
| 4 | С какой фразы начинается первый ответ клиенту? | false | В документе «Шаблоны ответов» первая фраза: «Здравствуйте! Я взял ваш вопрос в работу.» | Шаблоны ответов |
| 5 | Что такое фрагмент в базе знаний? | false | В документе «Словарь терминов» фрагмент — это абзац документа, по которому выполняется поиск. | Словарь терминов |
| 6 | Кто подтверждает запуск задачи? | false | В документе «Процесс запуска задачи» запуск подтверждает тимлид. | Процесс запуска задачи |
| 7 | Что новичок читает в первый день? | false | В документе «Правила работы команды» новичок читает правила, словарь терминов и процесс запуска задачи. | Правила работы команды |
| 8 | Какой годовой бюджет отдела маркетинга? | true | Сумм, бюджета и маркетинга ни в одном документе нет. | — |
| 9 | Какой пароль от рабочей почты руководителя? | true | Паролей и доступов к почте в документах нет. | — |
| 10 | В каком городе находится запасной склад? | true | Городов и складов в документах нет. | — |
